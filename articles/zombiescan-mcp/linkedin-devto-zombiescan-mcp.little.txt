Put the Arithmetic in the Tool: an MCP Server for an AWS Waste Scanner

A cost report gets read twice: once by a person in a terminal, once by an agent through an MCP server. Making the server compute every total instead of handing back rows keeps the two answers the same, and measures the report's own arithmetic against the AWS bill.

What is in it:

- 🟢 Five read-only MCP tools over stdio, JSON-RPC 2.0, standard library only
- 🟢 One scan of 17 regions: 120 findings, $6.90 a month, $82.80 a year
- 🟢 estimate\_savings answers totals, counts, extremes and three breakdowns from one call
- 🟢 A filter that matches nothing reports which of its terms the report never held
